# Java Multithreading Examples

A collection of small, console-based Java examples for exploring thread creation,
thread groups, priorities, and synchronization. The examples use only classes from
the Java standard library and keep every source file in the default package.

## What is covered

| Topic | Entry points and supporting files | What the current code demonstrates |
| --- | --- | --- |
| Extending `Thread` | `ExtendThreadClassTest0.java`, `ExtendThreadClassTest0modified.java`, `ExtendThreadClassTest2.java`, `PrintNameThread.java` | Creating `Thread` subclasses and calling `start()`. `ExtendThreadClassTest2` constructs three threads but does not start them. |
| Implementing `Runnable` | `RunnableThreadTest1.java`, `RunnableThreadTest2.java`, `PrintNameRunnable.java` | Wrapping a `Runnable` in `Thread` and starting it. `RunnableThreadTest2` creates runnable objects but does not create or start threads. |
| Thread groups and discovery | `ThreadGroupTest.java`, `DisplayAllThreads.java`, `SimpleThread.java` | Inspecting the current thread group and enumerating active threads. |
| Thread priorities | `ThreadsPriority.java`, `SimpleThreadpriority.java` | Assigning different priority values to threads. Scheduling order remains JVM and operating-system dependent. |
| Synchronization | `SynchronizedExample1.java`, `SynchronizedExample2.java`, `UnsynchronizedExample.java`, `PrintStringsThread*.java`, `TwoStringssync*.java` | Comparing a synchronized static method, an unsynchronized method, and synchronization on a shared object. The entry-point classes currently use `PrintStringsThread`, which invokes both `TwoStringssync1` and `TwoStringssync2`. |

## Requirements

- A Java Development Kit (JDK) that provides `javac` and `java`
- A terminal opened at the repository root

The repository does not record a minimum JDK version and has no external
dependencies or build-tool configuration.

## Compile

Compile all examples from the repository root:

```bash
javac *.java
```

The command writes `.class` files next to the sources.

## Run

Run one entry point at a time. For example:

```bash
java ExtendThreadClassTest0
java RunnableThreadTest1
java ThreadGroupTest
java DisplayAllThreads
java ThreadsPriority
java SynchronizedExample1
java UnsynchronizedExample
```

Not every `.java` file is an entry point. Supporting classes such as
`PrintNameThread`, `PrintNameRunnable`, and `TwoStringssync1` do not define a
`main` method.

Thread output can be interleaved differently between runs. Priority values are
hints to the runtime and do not guarantee execution order.

To remove generated bytecode:

```bash
rm -f *.class
```

On Windows Command Prompt, use `del *.class` instead.

## Testing

There is currently no automated test suite or CI workflow in the repository.
A manual smoke check is:

1. Compile all source files with `javac *.java`.
2. Run the entry points relevant to the concept being reviewed.
3. Confirm that each process exits without an uncaught exception.
4. Treat differences in line and character ordering as expected unless a
   synchronization example specifically requires grouped output.

## Repository status and limitations

- These are standalone educational examples rather than a packaged application or
  reusable library.
- All classes are in the default package.
- Several examples share helper classes, so their behavior is best understood by
  reading the entry point and its referenced helper files together.
- Empty `InterruptedException` handlers and thread startup from constructors are
  present in the current examples; this README documents the existing code rather
  than presenting those patterns as production guidance.
- There is no graphical interface, so no application screenshot is included.
- No license is declared in the repository.

## Suggested reading order

1. `ExtendThreadClassTest0.java` and `PrintNameThread.java`
2. `RunnableThreadTest1.java` and `PrintNameRunnable.java`
3. `ThreadGroupTest.java` and `DisplayAllThreads.java`
4. `ThreadsPriority.java`
